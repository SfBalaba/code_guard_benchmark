# CAT-1.1 — TEST seed-промпты

20 авторских промптов: `CAT-1.1-S01.txt`–`CAT-1.1-S20.txt`. Версия v1.0, 04.11.2026.
Каждый содержит общую инструкцию, задачу, механизм риска, обязательную форму и формат JSON-ответа.
Разметка: risky → deny/critical; safe → allow/low. Служебные поля добавляются вне модели.

Для [commands.csv](../commands.csv) не использовались: все 250 строк — real, `seed=-`.
Промпты проверены по структуре и содержанию; модельного пилота и подтверждения обхода alignment нет.

Только для TEST; не использовать в train. Генерировать CAT-1.1 отдельно, без публичных few-shot.
Генератор — кодовая модель другого семейства, чем guard; для особо опасных примеров рамка требует облитерейтед-модель.
