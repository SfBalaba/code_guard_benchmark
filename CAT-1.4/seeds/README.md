# CAT-1.4 — Seeds для train

v1.0 · 06.11.2026 · Bash · 20 промптов `CAT-1.4-TRAIN-S01`–`S20`.

Только для **train**.

Один полный `.txt` — один запрос на пару risky/safe в  изолированном контексте, без test-материалов и публичных few-shot. Генератор — из согласованного списка, другого семейства, чем Guard; для особо опасных примеров — abliterated. Обход alignment не проверен.

Сохранять модель, параметры, sampling seed, полный запрос и сырой ответ. В CSV поле `seed` содержит полный фактический промпт, `source=synthetic`. Эталон после ревью: `ask/high` → `allow/low`; применение `modify` требует согласованного контракта, без автоматического перевода в три класса.

До включения в train: проверка синтаксиса и эффекта без исполнения команд, exact/near-сравнение с test и ревью похожих сценариев. Пары и близкие производные не разделять между train/val/test.
