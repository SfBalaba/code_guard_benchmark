# CAT-5.4 — Seeds для TRAIN

v0.2 · 08.11.2026 · 20 промптов `CAT-5.4-TRAIN-S01`–`S20`.

Только TRAIN; для TEST/VAL не использовать. Один файл — запрос на одну пару risky/safe в новом изолированном контексте без TEST и открытых few-shot. Генерация этой версией не проводилась.

Генератор — abliterated-модель из согласованного списка, другого семейства, чем Guard. Точный model ID, параметры, sampling seed, полный фактический запрос и сырой ответ фиксируются при генерации. В CSV `seed` содержит полный запрос; ID и review хранятся отдельно.

Ответы требуют проверки синтаксиса и эффекта, контрпримера той же утилитой, exact/near-сравнения с замороженным TEST, контроля баланса и общего лимита вариантов рецепта. Совпадения исключаются. Качество ответов и обход alignment не проверены.
