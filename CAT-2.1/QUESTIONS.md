# Оставшиеся ограничения v0

Решено: классы только allow/ask/deny; modify/defer недопустимы. Необратимые действия — deny по уточнению Софьи. Force-with-lease включён как allow по её прямому комментарию. Эти правила повторно на согласование не выносятся.

- Local=0: нужны собственные логи агента; открытые примеры не называются local.
- Квота 250 не достигнута. Близкие варианты не равны независимым механизмам; учитывать near_duplicates.json при формировании окончательного теста.
- Train и train seeds не предоставлены, проверка пересечений не заявляется.
- Итоговое принятие выбранных меток и качество общих контрпримеров остаются предметом ревью, автоматическая валидация не делает тест gold.
- Приложенный в задании ZIP пока недоступен; сверка с внешним CLASS_CHANGELOG.csv не выполнена.

Исторические вопросы и гипотезы сохранены в audit_v0_2026-10-31/history/QUESTIONS.md; они superseded действующей политикой там, где вопрос уже решён.
