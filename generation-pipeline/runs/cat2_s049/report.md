## Гейт 3: выход

**Калибровка порога** (`threshold_calibration.json`).
- Порог 0.5 на ядрах CAT-2 не подходит. Все сценарии берут цели из одного словаря (origin, `refs/heads/demo-X-work:…-review`, `drafts/demo-X notes.txt`, `src/demo-X.c`, `*.keep`, `cache/`). Поэтому в 2.1 у 52% пар ядер из разных сценариев Jaccard ≥0.5, и sweep схлопывает 199 ядер в 18.
- В полосе 0.5–0.7 сливаются противоположные по смыслу пары: `--force` против `--force-with-lease`, lease против mirror.
- В полосе 0.8–0.9 в основном перестановки флагов (`-fdx` против `-f -x`). Поэтому внутри train взят порог 0.8 по маскированной паре ядер. Это экспертный выбор, разметки precision/recall нет.
- По развёрнутому тексту доминирует обёртка (медиана 0.45–0.63 при одной форме в разных сценариях), поэтому дедуп шёл по ядрам.
- Против test — консервативные 0.5, плюс пулы. Cap — 5 на семейство.

**Разнообразие (правило 8): фактически шаблон с подстановкой.**
- Утилиты: в 2.1–2.3 — 100% `git`. В 2.4 `git` 53%, `ls` 27%, `cat` 15%, `rm` 4%.
- Цели во всех 140 сценариях из одного словаря, меняется только hex.
- 36 конструкций (`bash -c`, eval, base64, рекурсия, alias, heredoc, trap) — детерминированные обёртки сборщика вокруг одного ядра.

**Артефакты.**
- Внешняя обёртка `(\n…\n)` — во всех 8 804 строках.
- `cgb_*` / `cgb-child` — примерно в 75% строк.
- `demo-<hex>` — в 40–89% строк, по подкатегориям.
- Для сравнения: в `data/test` 20 строк с обёрткой и 73 с `cgb` (test CAT-6.2–6.5 и CAT-5.2 используют тот же префикс), в v0 ни того ни другого.
- Риск ярлыка: классификатор может выучить «скобка + cgb», то есть CAT-2 или CAT-6. Отдельно не измерялся.
- Из `command` ничего не вырезано (правило 9).

**Качество ядер.**
- 2.1: несуществующие флаги `push --preview` в 489 ядрах, `--lease` в 128, `--expected-old` в 62; `config --global` в 4.
- 2.2: `--no-pager` после подкоманды в 961 ядре.
- 2.3: `--ignored-only` в 13 ядрах; в 21 выжившей паре исходная сторона — не `git clean` (например `git push`).
- Валидатор: в 73 из 209 выживших пар есть фиктивные флаги.
- Ручная выборка 24 выживших пар: сценарий корректно реализован примерно в 3–4. Ожидаемо меньше 10 годных пар на подкатегорию.
