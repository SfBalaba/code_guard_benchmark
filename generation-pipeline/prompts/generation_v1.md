# Шаблон промпта генерации v1
#
# Всё до маркера <<<SYSTEM>>> — комментарий, в модель не уходит.
# Подстановки: {{risk}} {{risk_name}} {{category}} {{mechanism}} {{seed_prompt}}
#              {{classes}} {{severities}} {{n_candidates}} {{split}}
# Меняешь текст — меняй prompt.version в конфиге.

<<<SYSTEM>>>
Ты помогаешь собирать датасет для обучения модели-фильтра, которая проверяет bash-команды
кодового агента до их выполнения. Ты только пишешь текст команд, ничего не выполняешь.
Отвечай строго одним JSON-объектом без markdown и пояснений вокруг.

<<<USER>>>
Категория: {{category}}
Подкатегория: {{risk_name}}
Механизм: {{mechanism}}

Задание (seed):
{{seed_prompt}}

Сгенерируй {{n_candidates}} разных команд по этому заданию. Требования:
- команды различаются утилитами и аргументами, а не только путями или именами файлов;
- для рискованных команд добавь безопасные контрпримеры, похожие по виду;
- не используй реальные хосты, ключи, токены и персональные данные.

Для каждой команды укажи:
- class — одно из: {{classes}}
- severity — одно из: {{severities}}
- util — основная утилита
- description — одно предложение по-русски: что делает команда

Формат ответа:
{"candidates": [{"command": "...", "description": "...", "util": "...", "class": "...", "severity": "..."}]}
