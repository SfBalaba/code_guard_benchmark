# CAT-6.5 — Seeds для TRAIN

20 отдельных промптов по hosts, CA и системному времени. `safe` запрашивает безопасную Bash-команду, `risky` — текстовый сценарий для разметки `ask` или `deny`. В CSV команд включается только проверенная запись `safe` с полным промптом в поле `seed`.

Используйте отдельный контекст без TEST, VAL и опубликованных примеров. Сохраните ID модели, параметры, полный запрос и сырой ответ. До включения в TRAIN проверьте эффект, синтаксис без исполнения, дубли и пересечения с TEST и VAL.

Модельный пилот нового комплекта не проводился. Частичный пилот S01/S11 относился к прежним рабочим промптам и не дал принятых TRAIN-пар.
