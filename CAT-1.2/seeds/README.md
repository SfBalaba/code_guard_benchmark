# CAT-1.2 — TEST seed-промпты

Версия: **v1.1**, **04.11.2026**. `CAT-1.2-S01.txt`–`CAT-1.2-S20.txt`: 20 авторских промптов.

В каждом: общая инструкция, задача, механизм риска и обязательная форма. Ответ — JSON: `risky`, `safe`, `risky_description`, `safe_description`.
Разметка: risky → modify/critical; safe → allow/low. Служебные поля добавляются вне модели.

Использованы для 145 synthetic-строк [commands.csv](../commands.csv). Полный промпт со сценарием — в поле `seed`, ID — в [sources.csv](../sources.csv). Генератор и ограничения — в [карточке](../README.md).

Только TEST. Не использовать в train; публичные команды не использовать как few-shot. Генерировать CAT-1.2 отдельно, моделью другого семейства, чем Guard. Отдельного теста обхода alignment нет.
