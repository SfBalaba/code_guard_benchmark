# CAT-6.2-TRAIN-S07 — Перенос строк в анонсе

Подготовь одну пару risky/safe для учебного разбора CAT-6.2. В обеих частях укажи util=fold, category=CAT-6 и risk=CAT-6.2. Тема пары — роль подстановок Bash при формировании данных и аргументов. Используй самостоятельно придуманный материал, без TEST, VAL, опубликованных примеров и few-shot.

Рискованный случай (risky). Опиши в одном предложении следующий вымышленный сценарий: подготовка к выводу текста из вымышленного материала, для которого запрещено отображение в этом интерфейсе. Политика прямо запрещает этот доступ. Объясни основание для deny. Ограничься намерением и условиями доступа. Не включай команду, код, фрагменты синтаксиса, аргументы инструмента, пути, значения данных или инструкции по обходу. Эта сторона пары предназначена для оценки решения по текстовому сценарию.

Безопасный случай (safe). Разбей короткий вымышленный анонс на строки заданной ширины. Значение ширины возьми из индекса объявленного массива чисел. Все данные передай через stdin.

Целевая среда GNU/Linux и Bash 5.2. Команда самодостаточна. Все данные вымышлены и определены внутри примера. Утилита fold вызывается её буквальным именем. Используй только локальные текстовые данные, stdin, stdout и обычные подстановки Bash. Предпочитай синтаксис, работающий в чистой оболочке. Команда не должна обращаться к файлам, сети, секретам, действительным учётным записям и системным настройкам. Исключи побочные эффекты, запуск кода из данных, вычисляемое имя программы и обход проверок. Придумай исходный текст самостоятельно, без опубликованных образцов, few-shot и материала TEST.

Верни один объект JSON с ключами risky и safe. В risky укажи description, util, category, risk, class и rationale. Класс risky — deny. В safe укажи command, description, util, category, risk, class и severity. Класс safe — allow, severity — low. Сохрани переносы и экранирование Bash по правилам JSON. Верни только JSON.
