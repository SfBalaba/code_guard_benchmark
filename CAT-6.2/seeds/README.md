# CAT-6.2 — Seeds для TRAIN

20 самостоятельных запросов, `CAT-6.2-TRAIN-S01.txt`–`CAT-6.2-TRAIN-S20.txt`. Один файл запрашивает одну пару `risky/safe` с общей утилитой и кодом `CAT-6.2`.

- `risky` содержит вымышленный сценарий для проверки разметки `ask` или `deny`. Решение следует из явно указанного условия доступа. Эта часть содержит только описание и обоснование, без команды Bash.
- `safe` содержит самодостаточную команду Bash с `class=allow` и `severity=low`. Подстановки формируют локальные данные и аргументы явно названной утилиты.

Исполняемая часть TRAIN из этих запросов покрывает только безопасные контрпримеры. Пары подходят для разбора разметки. Для полного набора команд по гайдлайну требуются пары из двух Bash-примеров.

Используйте запросы только для TRAIN. Передавайте каждый файл целиком в отдельном контексте без TEST, VAL, опубликованных примеров и few-shot. Согласно ТЗ для генерации используется согласованная abliterated-модель другого семейства, чем обучаемая модель. Запишите точный ID модели, параметры, полный запрос и исходный ответ. При отборе со случайной выборкой зафиксируйте `random_state`.

Модель возвращает один объект JSON с ключами `risky` и `safe`. Сверьте `util`, `category` и `risk` обеих частей. При экспорте берите только принятую запись `safe` и используйте порядок колонок `command,description,util,severity,category,risk,source,seed,class`. Дополните запись полями `source=synthetic` и `seed` с полным фактическим запросом. Сохраните переносы и экранирование Bash при записи CSV. Сценарий `risky` храните отдельно от CSV команд.

Перед добавлением в TRAIN проверьте синтаксис Bash 5.2 в режиме `-n`, однозначность эффекта и соответствие описания. Сверьте точные и тривиальные близкие дубли внутри TRAIN и пересечения с TEST и VAL. Эта сверка относится к результатам генерации. Модельный прогон по этим запросам ещё не проводился.
