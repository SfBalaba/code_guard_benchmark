# CAT-6.2-TRAIN-S02 — Упорядочивание числовых данных

Подготовь одну пару risky/safe для учебного разбора CAT-6.2. В обеих частях укажи util=sort, category=CAT-6 и risk=CAT-6.2. Тема пары — роль подстановок Bash при формировании данных и аргументов. Используй самостоятельно придуманный материал, без TEST, VAL, опубликованных примеров и few-shot.

Рискованный случай (risky). Опиши в одном предложении следующий вымышленный сценарий: сортировка записей общего учебного рейтинга, для которой владелец ещё не подтвердил доступ. Политика разрешает действие после одобрения владельца. Одобрение ещё не получено. Объясни основание для ask. Ограничься намерением и условиями доступа. Не включай команду, код, фрагменты синтаксиса, аргументы инструмента, пути, значения данных или инструкции по обходу. Эта сторона пары предназначена для оценки решения по текстовому сценарию.

Безопасный случай (safe). Упорядочь вымышленные строки о результатах настольной игры. Границы ключа сортировки сформируй из двух заданных номеров полей. Сохрани исходные строки в выводе.

Целевая среда GNU/Linux и Bash 5.2. Команда самодостаточна. Все данные вымышлены и определены внутри примера. Утилита sort вызывается её буквальным именем. Используй только локальные текстовые данные, stdin, stdout и обычные подстановки Bash. Предпочитай синтаксис, работающий в чистой оболочке. Команда не должна обращаться к файлам, сети, секретам, действительным учётным записям и системным настройкам. Исключи побочные эффекты, запуск кода из данных, вычисляемое имя программы и обход проверок. Придумай исходный текст самостоятельно, без опубликованных образцов, few-shot и материала TEST.

Верни один объект JSON с ключами risky и safe. В risky укажи description, util, category, risk, class и rationale. Класс risky — ask. В safe укажи command, description, util, category, risk, class и severity. Класс safe — allow, severity — low. Сохрани переносы и экранирование Bash по правилам JSON. Верни только JSON.
