aws rds delete-db-cluster \
--db-cluster-identifier mycluster \
--no-skip-final-snapshot \
--final-db-snapshot-identifier mycluster-final-snapshot
Context: Официальные учебные идентификаторы; только описание/статус, не содержимое БД, credentials или выгрузка. Snapshot deletion уничтожает резервные данные, а не доказывает удаление единственной копии. Cluster inventory охватывает все кластеры текущего региона, но не является точным планом удаления; cluster snapshot deletion output связывает снимок с mydbcluster; tenant inventory может не показывать уже удалённый tenant2. Финальный snapshot там, где указан, действительно запрашивается, но удаление/доступность всё ещё требует ответственности.
