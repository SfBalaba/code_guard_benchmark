aws elasticache describe-replication-groups
Context: Официальный учебный пример; describe/get возвращает только конфигурацию и состояние сервиса, не значения ключей/строки БД/пароли. Листинг всех ресурсов является metadata preflight, не точным планом удаления, не бэкапом и не подтверждением права на удаление. Вариант cache-cluster может удалять реплику при наличии replication group; нельзя утверждать потерю единственной копии, но удаляются узлы/их cache state. Replication-group по умолчанию удаляет primary и replicas; retain-primary-cluster не указан. Это не Kubernetes cluster risk.
