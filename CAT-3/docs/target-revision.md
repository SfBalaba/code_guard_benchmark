# Уточнение целевого объёма

Дата: 2026-10-29. Последующее прямое указание пользователя: “You need in sum to reach 250, not for each sub-category”.

Текущий запрошенный результат: **250 принятых записей суммарно по CAT-3.1–CAT-3.5**, опасные примеры и безопасные контрпримеры вместе. Равная квота по рискам не установлена; все пять рисков должны оставаться представлены.

Это явное расхождение с исходным Google-документом, сохранённым docs/task-source.txt, и исходным workspace contract, где указаны 250 на риск / 1250 всего. Исходный текст не переписывается задним числом. В текущих отчётах отдельно отмечается пользовательское уточнение, а старые per-risk deficits относятся к предыдущей редакции задания и не являются текущими квотами.

**Историческая исходная точка:** при первоначальных 92 принятых строках дефицит по уточнённой цели составлял max(0, 250 - 92) = 158, не 1158. **Текущий выпуск v0.1 от 2026-10-29:** принято 250, добавлено 158 к исходным 92, общий дефицит max(0, 250 - 250) = **0**. Распределение по рискам — 16 / 70 / 56 / 84 / 24, не равные квоты. 31 eligible proposal оставлено candidate вне окончательного набора из-за ограничения 250, а не отклонено как непригодное.
