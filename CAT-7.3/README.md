# CAT-7.3: тестовый набор для ревью

250 команд из открытых источников, 19.11.2026. Классы: {'allow': 247, 'deny': 3}.
Квота включает безопасные контрпримеры. Предварительная агентская разметка
по трёхклассовой политике S055: allow/ask/deny. Это не human gold.

Основной файл — [commands.csv](commands.csv), девять колонок в принятом порядке:
command, description, util, severity, category, risk, source, seed, class.
CSV побайтно сохранён из локального CAT-7 test v1; команды и метки не менялись.
Многострочные команды читаются CSV-парсером, число физических строк не равно числу записей.

Дополнительные файлы:
- inputs/commands.jsonl — те же 250 записей, только id/command для Judge;
- reference/labels.jsonl — классы, причины, policy/family IDs;
- provenance.jsonl — исходные URL, ревизии, хеши, позиции и преобразования;
- attribution.jsonl — авторы и лицензии публикаций Stack Exchange;
- LICENSES/ — доступные уведомления источников и перечень недостающих;
- source_groups.jsonl, near_duplicate_audit.json — связанные источники/примеры;
- validation.json, MANIFEST.json — проверки и контрольные суммы.

Три ветки CAT-7.1/7.3/7.5 вместе содержат 750 уникальных текстов, 640 allow,
34 ask, 76 deny. Источники и классы несбалансированы. В общем v1-аудите
воспроизведены 961 origin по 269 снимкам; точного пересечения с прежними
8916+1064 экспортными входами не найдено. Семь близких повторов заменены,
46 связанных пар оставлены. Независимость семейств не установлена.
Проверка train затронула 1281 локальный файл; внешние train-наборы не проверены.

Только test/review; не использовать в train, генерации или few-shot.
annotation_status=agent_preliminary, human_gold=false,
semantic_validation=false, publication_ready=false, owner_review_required=true.
Публикация рабочей ветки разрешена пользователем; эти статусы качества не менялись.
Команды корпуса не исполнялись. Метки не означают гарантированную исполнимость
в произвольной оболочке или контексте. Модели и Judge для публикации не вызывались.

Исходные лицензии и авторские уведомления сохраняют силу. Набор не получает
единой новой лицензии; LICENSES/inventory.json явно отмечает отсутствующие
сохранённые лицензии. Attribution и ссылки сохранены; полный юридический аудит
не заявляется. Снимки в provenance — ссылки на локальный исследовательский архив,
он не включён в ветку. Для просмотра исходников используйте URL с ревизиями.
Локальные пользовательские логи, карантин, train-сиды и модельные ответы сюда не входят.
