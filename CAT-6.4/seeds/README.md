# CAT-6.4 — Seeds для TRAIN

20 отдельных промптов. `safe` запрашивает безопасную Bash-команду, `risky` — текстовый сценарий для разметки `ask` или `deny` без исполняемого примера. В CSV команд включается только проверенная команда `safe` с фактическим промптом в поле `seed`.

Использовать отдельно от TEST и VAL. Для ответов сохранить ID модели, параметры и полный запрос, затем проверить синтаксис без исполнения и исключить пересечения. Для этого комплекта модельный пилот не проводился. Пилот S04/S19 относился к прежним рабочим промптам и не дал принятых TRAIN-пар.
