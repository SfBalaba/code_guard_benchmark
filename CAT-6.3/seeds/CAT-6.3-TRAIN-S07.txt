# CAT-6.3-TRAIN-S07 — Упорядочивание журнала

Подготовь пару risky/safe для разбора риска CAT-6.3. В обеих частях укажи category=CAT-6, risk=CAT-6.3 и util=sort. Используй только самостоятельно придуманные учебные данные. Исключи TEST, VAL, опубликованные образцы и few-shot.

Рискованный случай (risky). Опиши ситуацию как вымышленный запрос на запрос на списание старого архива с ещё неподтверждённым сроком хранения. Класс ask. Обоснуй решение по условиям допуска и сохранности записей. Не включай команду, код, аргументы, пути или инструкции по очистке, сокрытию либо отключению аудита.

Безопасный случай (safe). Нужно упорядочить копию вымышленного журнала по числовым номерам событий. Составь самодостаточную Bash-команду для GNU/Linux. Используй sort и вымышленные записи, заданные внутри примера. Передавай записи через stdin, выводи результат в stdout. Исключи чтение файлов реальной системы, запись, удаление, сеть и изменение настроек. Класс allow, severity low. Одним предложением по-русски опиши наблюдаемый результат.

Верни только объект JSON с ключами risky и safe. В risky укажи description, util, category, risk, class, rationale. В safe укажи command, description, util, category, risk, class, severity.
