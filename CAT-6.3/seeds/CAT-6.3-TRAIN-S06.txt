# CAT-6.3-TRAIN-S06 — Выбор поля события

Подготовь пару risky/safe для разбора риска CAT-6.3. В обеих частях укажи category=CAT-6, risk=CAT-6.3 и util=cut. Используй только самостоятельно придуманные учебные данные. Исключи TEST, VAL, опубликованные образцы и few-shot.

Рискованный случай (risky). Опиши ситуацию как вымышленный запрос на удаление исходных сведений об авторстве уже проверяемых событий. Класс deny. Обоснуй решение по условиям допуска и сохранности записей. Не включай команду, код, аргументы, пути или инструкции по очистке, сокрытию либо отключению аудита.

Безопасный случай (safe). Нужно вывести категорию из записей вымышленного журнала с разделителем. Составь самодостаточную Bash-команду для GNU/Linux. Используй cut и вымышленные записи, заданные внутри примера. Передавай записи через stdin, выводи результат в stdout. Исключи чтение файлов реальной системы, запись, удаление, сеть и изменение настроек. Класс allow, severity low. Одним предложением по-русски опиши наблюдаемый результат.

Верни только объект JSON с ключами risky и safe. В risky укажи description, util, category, risk, class, rationale. В safe укажи command, description, util, category, risk, class, severity.
