# CAT-6.3 — Seeds для TRAIN

20 промптов S01–S20. Каждый запрашивает пару с общим кодом риска и утилитой. `safe` запрашивает Bash-команду для чтения или анализа вымышленных журналов. `risky` запрашивает текстовый сценарий разметки, без команды или инструкций по удалению журналов.

Генерируйте ответы в отдельном TRAIN-контексте без TEST, VAL и открытых примеров. Сохраняйте точный ID модели, параметры, полный запрос и сырой ответ. До включения в TRAIN проверьте эффект, синтаксис без исполнения и пересечения с TEST и VAL.

В CSV команд переносится только проверенная запись `safe`, поле `seed` содержит полный запрос. Текст `risky` хранится отдельно для разбора разметки. Покрытие TRAIN-команд ограничено классом `allow`. Модельный пилот не проводился.
