# CodeGuardBench — CAT-1.3 Low-Level Storage Overwrite

**Язык:** Bash · **Версия:** v0-draft-review · **Дата:** 2026-10-28 · **Ветка:** `feat/data_CAT-1.3`.

## Описание и покрытие

Риск — запись на реальное блочное устройство или раздел, форматирование, стирание сигнатур и изменение таблицы разделов. Безопасные аналоги относятся к тому же CAT-1.3 и имеют class=allow.

Покрыта одна подкатегория: **CAT-1.3 — 52 записи**, 26 пар "опасный пример + безопасный аналог". 

Цель — 250 примеров команд на подкатегорию.

**Утилиты и конструкции — число записей в обеих частях:** `blkdiscard` — 4, `cat, Bash` — 2, `dd` — 10, `echo, sfdisk` — 6, `mke2fs` — 4, `mkfs.ext4` — 4, `printf, Bash >` — 2, `sfdisk` — 6, `shred` — 4, `sudo, mkfs.xfs` — 2, `tee` — 2, `wipefs` — 6.

Оба CSV: UTF-8, разделитель — запятая, девять колонок в порядке:

`command,description,util,severity,category,risk,source,seed,class`

Category — CAT-1 Деструктивные файловые операции, risk — CAT-1.3 Low-Level Storage Overwrite. Для несинтетических записей seed=-. Исходные пробелы, кавычки, операторы, escape и переводы строк команд сохранены.

## Синтетика и отбор

Модель генерации первых 38 synthetic-записей — **gpt-6.1-sol**. В seed этих записей указан технический промпт повторной генерации, восстановленный по сценарию после создания данных. Это не исходный промпт первой генерации, его точная воспроизводимость не заявляется. Для real seed=-.

Для 3 новых synthetic-записей сценарные промпты сохранены до генерации и дословно записаны в seed. Модель — **GPT-6**, генерация в текущей сессии, точный идентификатор обслуживающей модели недоступен.

Отбор исходных примеров целевой, не случайный. Для общего группового разбиения использован **random_state=20261027**, для этой папки повторного случайного отбора не было. Три новые пары добавлены целевым отбором, одна целиком помещена в test, две — в основную часть, прежнее разбиение сохранено.

## Пограничные случаи и условия разметки

Отдельно отложенных кандидатов этой подкатегории в папке нет. Ситуации, требующие проверки при ревью:

- Для опасных сценариев устройство существует, содержит нужные данные, доступно для записи, а разрушительная операция не разрешена, необходимые функции поддерживаются реализацией и устройством.
- Для аналогов с обычным образом подтверждаются тип файла, одноразовое содержимое и разрешение пользователя. Одного расширения .img недостаточно.
- Ограничение размера или числа проходов не гарантирует сохранность метаданных, backup сигнатур или разметки не заменяет разрешение на изменение.
- Режим без записи, чтение и явно неисполняемая ветка отличаются от разрушающего действия. Защитные флаги проверяются для конкретной утилиты и её версии.
- Наличие /dev в строке само по себе не означает deny: важны направление ввода/вывода, флаги и достижимость команды. Точные предпосылки требуют технической проверки при приёмке.

Опасные сценарии размечены deny/high или deny/critical, безопасные аналоги — allow/low по заявленным условиям. Не являются универсальными метками для любого запуска той же утилиты. Внешний контекст сервису guard автоматически не доступен, поэтому протокол его использования еще нужно согласовать с участником стрима D3.

## Тестовая выборка и ограничения

Основная и тестовая части не пересекаются по точным командам, сравнительным каноническим формам и исходным группам. Пары сохранены целиком. Тестовые команды не приводятся в README. 

Test не использовать для обучения или демонстраций в промптах. Description, class, severity, source и seed — метаданные.

- Test содержит 4 записи и не согласован с участником стрима D3, для устойчивой оценки метрик его недостаточно.
- Большинство примеров синтетические, независимое техническое ревью, оценка сложности аналогов и полная семантическая дедупликация не завершены.
- Обфускации не включены: требуется согласовать требование гайдлайна с отнесением техники сокрытия к CAT-6.
- Для большинства источников версии бинарных утилит и commits документации не закреплены. Проверка поведения в среде выполнения не проводилась, команды примеров не исполнялись.
