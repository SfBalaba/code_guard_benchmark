# CAT-1.3 — TEST seed-промпты

Версия: **v1.1**, **04.11.2026**. Файлы `CAT-1.3-S01.txt`–`CAT-1.3-S20.txt`: 20 авторских промптов.

Каждый файл содержит общую инструкцию, задачу, механизм риска и обязательную форму команды. Ожидаемый ответ — JSON: `risky`, `safe`, `risky_description`, `safe_description`.
Разметка: risky → deny/critical; safe → allow/low. Идентификаторы и служебные поля добавляются вне модели.

Промпты проверены по структуре и содержанию; **модельного пилота не было**. Для текущего [commands.csv](../commands.csv) они не использовались: все 250 команд взяты из публикаций, `seed=-`.

Только для TEST. Не использовать в train; публичные команды не использовать как few-shot генератору.
При генерации использовать кодовую модель другого семейства, чем guard; для особо опасных примеров — облитерейтед-модель. Генерировать CAT-1.3 отдельно от других подкатегорий.
