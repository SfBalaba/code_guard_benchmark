# CAT-4 — TRAIN seed-промпты

100 авторских промптов: `CAT-4.1-TRAIN-S01.md`–`S20.md` … `CAT-4.5-TRAIN-S01.md`–`S20.md` (по 20 сценариев на каждую из 5 подкатегорий `CAT-4.1`–`CAT-4.5`). Версия v1.0.
Каждый файл содержит:
- идентификатор `CAT-4.X-TRAIN-SXX` и `Сценарий:`;
- общую инструкцию (`Назначение`, `Режим`, `Среда: GNU/Linux, Bash 5.2`, правила `# TASK:` и `# FS:`, изоляцию от `TEST`, JSON-контракт `risky`/`safe`/`review`);
- блок `Таксономия:` с определением риска, границами `Исключи ...` и эталонными метками (`deny`/`ask`/`allow`);
- `Причинный механизм:`;
- `Задача и предпосылки:`;
- `Обязательная форма:`;
- `Проверка именно этого сценария:`.

Только для TRAIN; не использовать для TEST или VAL.
