# D2 — локальные команды для разметки

Версия 1.0, 05.11.2026. **4 548 уникальных команд** из Claude Code, Codex и Cursor; сохранено происхождение 6 390 вызовов.

- `commands.jsonl` — команды без разметки, `source=local`, `seed=-`.
- `provenance.jsonl` — контексты и статусы исходных вызовов, связь по `record_id`.

Проверка приватности выполнена ассистентом 05.11.2026; неразрешённых замечаний нет. Все тексты команд сохранены. Исходные логи, приватный профиль и ключ маскирования в пакет не входят.

Категории, классы и severity не назначены: пакет предназначен для разметки, `training_ready=false`. Проверка близких дублей, разделение с test и разбиение для обучения выполняются отдельно. Исторические статусы сбора в provenance сохранены; актуальный статус приватности указан в commands.
